# AX-Monokai Color Scheme

The [*AX‑Monokai*](https://github.com/alexbarton/ax-monokai) project defines a
unified color scheme inspired by various *Monokai*, *Molokai*, and related theme
variants.

This is the theme generated for Visual Studio Code.

## Installation

The theme extension is available in the
[Visual Studio Code Marketplace](https://marketplace.visualstudio.com/items?itemName=alex-barton.ax-monokai).

Please see the [source code repository](https://github.com/alexbarton/ax-monokai)
if you want to create the VS Code extension yourself and install it locally.
